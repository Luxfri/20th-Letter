# Birthday letters

Files
- index.html : the page (no need to edit)
- config.js  : names, letters, quotes, captions, photo paths  <- edit this
- photos/    : put your pictures here, then list them in config.js

Preview locally: double-click index.html.

Deploy (pick one, all free)
1. Netlify Drop: go to app.netlify.com/drop and drag this whole folder in. You get a link right away.
2. GitHub Pages: push the folder to a repo, then Settings > Pages > deploy from main branch.
3. Vercel: run `npx vercel` inside this folder, or import the repo at vercel.com.

Tip: anyone with the link can open it, so send it only to her.
